How the connection works

This page makes a direct, encrypted WebRTC connection between the two browsers. It does not send video through a website server.

Connection steps: the camera owner starts sharing and sends an offer; the viewer returns an answer. These are temporary connection details, not a camera password, and can contain network-address information. Share them privately.
Network note: a public STUN service helps browsers find a direct route and may see network connection metadata. Some networks block direct connections, so this may not work everywhere. No TURN relay or recording service is included.
Browser note: use a recent version of Chrome, Edge, or Firefox. Camera access requires a secure browser context (HTTPS, or a browser that permits local files); use an HTTPS copy if your browser blocks camera access from the file.
Safety: only exchange offers and answers with the intended person. Stop sharing or close this page to end access. Never approve a camera prompt for someone you do not trust.
